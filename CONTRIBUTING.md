# Contribution Policy

[**English**](CONTRIBUTING.md) | [简体中文](CONTRIBUTING.zh-CN.md)

AEC-S is maintained solely by Aphelion_Lab at this stage. The official repository is not accepting external source-code contributions, pull requests, patches, or other code submissions.

Please do not open a pull request with code changes. Unsolicited pull requests may be closed without review, and submitting code does not transfer ownership or grant Aphelion_Lab any right to use it.

You may fork, study, and modify AEC-S independently only for purposes permitted by the [PolyForm Noncommercial License 1.0.0](LICENSE). Any distribution must comply with that license and preserve both Required Notices in the [Attribution Notice](NOTICE).

This policy may change in the future. A later contribution process, if introduced, will be documented explicitly and may require a separate contributor agreement.
